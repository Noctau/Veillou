# Veillou — Dev plan (Part 2)

Формат как в Part 1: **веха → задачи на одну сессию с ЛЛМ (1–3 ч)**, у каждой есть DoD. Отмечай `[x]` и коммить план вместе с кодом. Нумерация продолжает Part 1 (M0–M13 закрыты, см. `Docs/part 1/DEV_PLAN.md`).

**Правила Part 2:**
- **Ветка:** вся разработка Part 2 ведётся в одной отдельной ветке `part-2` (создана от `main` в M14). В `main` — только после закрытия этапа.
- **Вехи вертикальные:** модель + миграция данных + API + UI в одной вехе. После каждой вехи приложением можно пользоваться каждый день.
- **Миграции на месте:** expand → backfill → переключение кода → contract (удаление старого — отдельной миграцией в конце вехи, после зелёных характеризационных тестов).
- **Характеризационные тесты M14.1 зелёные после каждой вехи M15–M20.** Снимок меняется только осознанно, с пометкой в коммите.
- Сценарии приёмки — `Docs/Part 2/TZ.md` §3.
